# Security policy

Security fixes target the latest stable release published on [GitHub Releases](https://github.com/andmetoo/lightcal/releases). Older releases are not patched.

Do not disclose exploitable vulnerabilities, secrets, or personal information in public issues.

If GitHub shows **Security > Report a vulnerability** for this repository, use that private reporting feature. Its availability must be verified by the maintainer; this file does not enable it. If it is unavailable, contact [@andmetoo](https://github.com/andmetoo) through an available profile contact method to arrange a private channel before sharing details. If no contact method exists, a public issue may request a private reporting channel without including vulnerability details.

Include the affected version, Windows version, reproduction steps, impact, and a minimal example without private user data. No response-time commitment has been established; this is a volunteer project.

Release builds on GitHub are unsigned until the maintainer signs them. Verify the SHA-256 files attached to the release and check the Authenticode signature before running a binary you downloaded.
