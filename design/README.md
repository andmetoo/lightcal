# Lightcal design

The design uses Penpot through MCP and the owner-selected icon in `assets/icons/better/`. See [Penpot design notes](penpot/README.md) and [icon notes](../assets/icons/README.md).

## Current Penpot design

The connected file is `app`. The redesigned calendar is 352 x 432 in tray mode and 520 x 600 in taskbar mode; settings are 780 x 620. The design covers both themes, weekday/date display, gray weekdays, current-month emphasis, event dots, settings, About links, and four-language examples. Calendar data is synthetic. Page organization and validation evidence are recorded in the Penpot notes.

## Sources and review

The editable design is organized on six pages: Overview, Calendar, Settings, States, Languages, and Design system. Source helpers, the verified page manifest, and reproduction instructions are in [penpot](penpot/README.md).

Mockups are design references, not an implementation of Windows behavior. Follow [required features](../docs/features.md) and [the validation protocol](../docs/validation.md) for implementation acceptance.
